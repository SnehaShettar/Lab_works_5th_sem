# Cloud Computing

This repository contains the laboratory experiments and practical work carried out as part of the **Cloud Computing** course.

The experiments are documented according to the sequence followed in the laboratory journal. Each experiment contains the problem statement, objectives, experimental setup, screenshots, observations, results, performance comparison, graphs, tables, and conclusion wherever applicable.

---

# Experiments

## Experiment 1 — Performance Analysis of Type-1 and Type-2 Hypervisors

This experiment studies the configuration and performance of virtual machines running on Type-1 and Type-2 hypervisor environments.

The experiment includes:

- Problem Statement
- Objective
- Type-1 Hypervisor setup
- Type-1 screenshots and results
- Type-2 Hypervisor setup
- Type-2 screenshots and results
- CPU performance benchmarking using Sysbench
- Performance comparison
- Comparison table
- Comparison graph
- Conclusion

## Experiment 2 — Performance Analysis of Virtual Machines and Containers

This experiment studies and compares the performance of virtual machines and Docker containers under controlled workloads.

The experiment includes:

- Virtual machine setup
- Docker container setup
- CPU performance
- Memory performance
- Disk I/O performance
- Network performance
- FastAPI application workload
- Application benchmarking
- Startup-time analysis
- Scalability analysis
- Result collection
- Statistical analysis
- Graphs and comparison tables
- Conclusion
